Order	Topic	What you need to understand
1	Object-Oriented Programming (OOP)	Classes, objects, methods, self, inheritance, composition
2	Graphs	Nodes, edges, neighbours, adjacency lists
3	Graph traversal	BFS (Breadth-First Search), DFS (Depth-First Search)
4	Pathfinding	Dijkstra's algorithm, shortest paths, weighted graphs
5	Python data structures	Dictionaries, sets, queues, collections.deque
6	File parsing	Reading map files, extracting data, validating input
7	Simulation logic	Turns, simultaneous movement, waiting, collisions
8	Capacity management	Tracking occupied zones and connections
9	Optimization	Distributing drones across routes to reduce total turns
10	Algorithm complexity	Big O notation, execution time, memory usage
11	Testing and debugging	Edge cases, exception handling, pdb
12	Code quality	Type hints, mypy, flake8, docstrings

Important distinction: The Fly-in subject requires graph-based routing,
 optimization, and object-oriented programming. BFS, DFS, Dijkstra, and
  deque are useful study topics, but the subject doesn't specifically
  require those algorithms or tools.

Start with OOP, because Fly-in explicitly requires a completely object-oriented 
implementation. Then study graphs and pathfinding, which form the core of the project.
